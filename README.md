# Product Review Sentiment Analysis

A Python-based NLP and Machine Learning project that classifies customer product reviews into **Positive, Negative, and Neutral** sentiments.

## Dataset
Women's Clothing E-Commerce Reviews Dataset  
[Hugging Face Dataset](https://huggingface.co/datasets/chibifire/kaggle-womens-ecom-clothing-reviews)

Sentiment labels are generated from ratings:
- 1–2: Negative
- 3: Neutral
- 4–5: Positive

## Technologies Used
- Python
- Google Colab
- Pandas, NumPy
- NLTK
- Matplotlib, Seaborn
- Scikit-learn

## Workflow
1. Dataset Collection and EDA
2. Text Preprocessing
3. Tokenization and Lemmatization
4. Feature Extraction (BoW and TF-IDF)
5. Model Training
6. Model Evaluation
7. Sentiment Prediction

## Algorithms Used
- Naive Bayes
- Logistic Regression
- Support Vector Machine (SVM)

## Evaluation Metrics
Accuracy, Precision, Recall, F1-Score and Confusion Matrix.

## Objective
To automatically analyse customer reviews and identify customer sentiment using NLP and machine learning.

## Future Scope
- Implement advanced models like BERT.
- Support multiple languages.
- Develop a web-based application.
